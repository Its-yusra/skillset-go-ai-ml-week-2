# skillset-go-ai-ml-week-2


## Overview

Week 2 focused on deep learning and PyTorch. The tasks covered neural networks, CNN image classification, hyperparameter experimentation, and technical reporting.

## Tasks Completed

### Task 2.1 — Neural Network in PyTorch

Implemented a feed-forward neural network using PyTorch for MNIST digit classification.

### Task 2.2 — CNN Image Classifier

Built and trained a Convolutional Neural Network using PyTorch and the CIFAR-10 dataset.

### Task 2.3 — Hyperparameter Experimentation

Tested different learning rates, optimizers, and batch sizes and compared their validation performance.

### Task 2.4 — Deep Learning Technical Report

Created a technical report summarizing the CNN implementation, experiments, findings, limitations, and future improvements.
